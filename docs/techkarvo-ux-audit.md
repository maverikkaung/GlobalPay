# TechKarvo အသုံးပြုမှုနှင့် ကုဒ်အခြေခံ စစ်ဆေးချက်

**Milestone 4.0 · `fa25e2fb415d64cbc5060fffd5e52afc17090a98` · `codex/marketplace-data-foundation`**

ဤစာတမ်းသည် React/Vite လမ်းကြောင်း၊ မျက်နှာပြင်၊ CSS၊ Supabase migration `000`–`017` နှင့် browser/SQL စမ်းသပ်ချက်များကို တိုက်စစ်ထားသည်။ Milestone 3 ၏ ခွင့်ပြုထားသော staging စမ်းသပ်မှုသည် **၈ အောင်၊ ၀ ကျ၊ ၀ ကျော်** ဖြစ်ပြီး migration `017`၊ RLS မူဝါဒ ၁၇၅ ခုနှင့် မူလ ledger row ၁၀၀ ကို အတည်ပြုထားသည်။ ဤရလဒ်၏ နယ်ပယ်မှာ မှတ်တမ်းတင်ထားသည့် Client/Freelancer စမ်းသပ်ခရီးစဉ်များဖြစ်သည်။ Production ဝန်ဆောင်မှုပေးသူ၊ အကောင့်ဆက်တင်နှင့် ဝန်ထမ်း workflow အပြည့်အစုံအတွက် သီးခြား စစ်ဆေးချက်လိုသည်။ [Milestone 3 မှတ်တမ်း](staging-verification.md)
